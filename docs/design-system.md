# PyMentor AI Design System

## Direction
"A well-set textbook with a live terminal."

## Palette Tokens (`app/globals.css`)
- **Light**: Paper `#F6F2EA`, Surface `#FFFDF8`, Ink `#16180F`, Muted `#5A5F55`, Line `#DCD5C7`, Accent `#1E5B45`, Code `#1B1D1A`
- **Dark**: Paper `#12140F`, Surface `#191C16`, Ink `#F2EEE3`, Muted `#A8AE9E`, Line `#2C3128`, Accent `#7FBF9E`, Code `#0C0E0B`

## Typography (2+1 Rule)
- **Display / Headings**: `Fraunces`
- **UI & Prose**: `Plus Jakarta Sans`
- **Code & Tabular Data**: `JetBrains Mono` (`tabular-nums`)

## Signature Components
- **LineByLineRail**: Two-column synchronized Python code and explanation rail.
- **DryRunTable**: Step-by-step variable state tracer with responsive mobile cards.
- **PythonSandbox**: Line-numbered editor, `stdin` drawer, and one-click `Debug with PyMentor`.
